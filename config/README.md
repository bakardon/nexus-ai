# NEXUS Configuration

This folder is intentionally easy to edit.

| File | Purpose |
|---|---|
| `personality.md` | Change NEXUS's personality, tone, and reasoning style |
| `memory.md` | Add/remove durable user context |
| `settings.yaml` | Enable features and change default model behavior |

You should not need to edit Python code for normal customization.

API keys belong in `.env`, which is ignored by Git. Start from `.env.example`.
