# NEXUS UI

The UI is designed as a visual task workspace rather than a conventional chatbot.

## Design direction

Inspired by the supplied product demo: a focused workspace, visible task state, files/artifacts, and an execution surface instead of a single giant chat transcript.

The UI should keep the following areas visible:

- **Task sidebar** — active and previous workspaces
- **Main workspace** — conversation, plan, and live execution
- **Context panel** — relevant memory, sources, and files
- **Artifact area** — generated documents/code/results
- **Approval bar** — explicit confirmation for external or write actions

Keep the interface clean and functional. Animations should communicate state, not decorate it.
